I am an AI Engineer, Data Scientist, and Systems Developer based in Noida, India. My work spans the entire spectrum from training machine learning models and crafting dense-retrieval RAG pipelines, to architecting high-frequency IoT predictive maintenance infrastructure and building deeply responsive full-stack applications.

When building the digital platform and studio operating system for Ritesh Farswan Photography, the goal was not to construct an ordinary portfolio template. The aim was to build an authentic analog tribute: fusing the tactile nostalgia of medium format 35mm film photography with modern reactive web engineering, Web Audio acoustic synthesis, cloud database synchronization, and background automation.

Every line of code in this project was composed with intention: from simulating the acoustic mechanical leaf shutter snaps in the browser without audio file overhead, to creating zero-latency darkroom amber safelight transitions, secure client PIN-based gallery proofing, and automated email notifications powered by Supabase Edge Functions.
